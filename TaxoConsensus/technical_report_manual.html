1. Application Description

TaxoConsensus Hub is an interactive web application developed in R Shiny. Its primary purpose is to assist researchers and epidemiologists in resolving the taxonomic status of medically important vectors and evaluating epidemiological risk.

The tool natively integrates generative artificial intelligence (Google Gemini) into the R environment, combining the rigor of classic data analysis with Natural Language Processing (NLP) capabilities, ensuring compliance with strict data integrity protocols.

2. Main Features

🛡️ A. Security and Auditing Architecture

  • Secure Authentication (shinymanager): Restricted access using credentials (e.g., evaluador or admin profiles).
  • Local Auditing (SQLite): Background logging system that records which user queries which species and at what time, ensuring traceability of AI usage.
  • BYOK Architecture (Bring Your Own Key): Allows users to input their own Gemini API Key, protecting the original project's billing quotas.

🧠 B. Artificial Intelligence Modules ("Zero Hallucinations")

  • Deterministic Prompting (Temp = 0.0): The model is configured to nullify "creativity," relying exclusively on verifiable scientific literature.
  • Semantic Grounding: Real-time connection with Google Search to cross-reference the LLM's internal knowledge base with updated taxonomic data.
  • Strict Formatting: Forces the AI to follow the Darwin Core (DwC) standard, generate references in APA format without DOIs/URLs (to avoid false links), and structure names as: Genus (Subgenus) species Author, Year.

📊 C. Explorer and Validation

  • Dynamic Vector Table: Interactive visualization of the curated project dataset with filters by taxonomic status and free-text search.
  • Cross-Auditing (GBIF): Automatic generation of buttons with encoded hyperlinks to verify each AI finding directly in the GBIF database.
  • Internationalization (i18n): Bilingual interface (Spanish / English) that changes reactively without needing to reload the page.

3. Usage Guide (Step-by-Step)

1

Authentication and Configuration

  1. Log in to the application using the assigned credentials (e.g., User: evaluador).
  2. In the left sidebar (Configuration), paste your Gemini API Key in the indicated field. If you do not have one, click the link below it to generate one for free in Google AI Studio. If left blank, the app will attempt to use the server's public quota.
  3. Select your preferred language.
2

Vector Analysis

There are two ways to analyze a taxon:

  • Via Explorer: Click on any row in the central table (Vector Explorer).
  • Via Free Search: In the left sidebar, enter the name of an unlisted species (e.g., Lutzomyia longipalpis) and press the "🔍 Analyze Species" button.
3

Results Review and Auditing

  1. Wait a few seconds while the assistant processes the information (an "Analyzing..." indicator will appear).
  2. Read the result in the AI Assistant panel. The response will be structured into:
    • Correct Name (Strict taxonomic format).
    • Justification (With bibliographic citations).
    • Medical Importance.
    • References.
  3. Final Audit: Click the "🔗 Verify on GBIF" button generated at the end of the response to cross-reference the AI's validation with official primary biodiversity records.
